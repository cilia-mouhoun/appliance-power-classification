# Project Proposal

## Objective

Develop a time-series classification model to automatically identify different appliances based on their power consumption patterns.

## Dataset

- Source: Appliance power consumption measurements
- Features: Time-series power values over time
- Classes: Different appliance types (e.g., Refrigerator, Microwave, Dishwasher, Washer, Dryer)

## Approach

1. **Feature Engineering**: Extract both temporal and spectral features from raw time-series
2. **Model Training**: Train multiple classification models
3. **Evaluation**: Compare model performance using standard metrics

## Expected Outcomes

- High-accuracy classifier for appliance identification
- Insights into discriminative features for different appliances
- Comparison of different classification approaches
